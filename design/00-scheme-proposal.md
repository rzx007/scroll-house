## 共享技术前提

```kv cols=2
* 单位: 1 three.js unit = 1 米，Y 轴向上
墙高: 2.80 m
外墙 / 内墙: 0.24 m / 0.12 m
图纸剖切高度: 1.20 m
室内眼高: 1.60 m
太阳: 傍晚低角度，暖色
素材: Poly Haven HDRI + ambientCG 贴图，均为 CC0
```

**图纸即模型。** 墙体只在 Y 方向生长，不做位移或替换。
墙高从 0 长到 2.80 m。墙高等于 1.20 m 的那一帧，画面就是标准平面图。

```flow LR
纸面 -> 墙体生长: 高度 0 -> 1.20 m
墙体生长 -> 平面图: 剖切帧
平面图 -> 墙体生长: 继续 -> 2.80 m
平面图 -> 镜头: 俯视 -> 下降 -> 入户
```

**一台相机走完全程。** 用 PerspectiveCamera 插值位置与视场角，全程不换相机。
图纸态 fov 为 12°，近似正交的图纸观感。室内态 fov 收到 55°，回到人眼视野。

```kv cols=2
* 图纸态: 位置 (0, 85, 0)，垂直向下，fov 12°
室内态: 眼高 1.60 m，fov 55°
过渡: 位置走弧线，fov 线性插值，无跳切
剖切: material.clippingPlanes 裁掉墙的上部，再补一层灰切面
线稿: 同一几何体的 EdgesGeometry 黑线，不是贴图
材质扫过: 每间房一个 uReveal，用噪声擦除从线稿过渡到 PBR
```

**家具自建。** 沙发、床、餐桌、柜体都用参数化几何生成。
这样家具也属于同一个模型，图纸上能看到家具的平面投影。

```ask
家具和材质怎么来？
* 参数化自建 | 与模型同源，零下载，图纸能看到家具投影
- CC0 模型 + 贴图 | 更真实，但要额外下载资产
- 结构自建，家具用 CC0 模型 | 折中
```

## Phase 1 交付范围

Phase 1 只做图纸、墙体升起、行进至第一个房间。做完先演示，再继续。

```tree
x3/
  index.html | 唯一入口，无构建
  styles.css | 页面与叠加层样式
  src/
    main.js | 渲染器、循环、Lenis 与 ScrollTrigger 接线
    layout.js | 建筑数据：房间矩形、墙段、门窗洞口、家具位
    build/
      shell.js | 由 layout 生成墙、地、顶几何
      plan.js | 图纸层：纸面、黑轮廓线、房间名与尺寸标注
      reveal.js | 剖切平面、切面封盖、逐房 uReveal 擦除
      furniture.js | 参数化家具
    camera/path.js | 关键帧定义与分段插值
    materials/library.js | 线稿与 PBR 两套材质注册表
  assets/
    hdri/dusk.hdr | Poly Haven CC0
    textures/ | ambientCG CC0
  vendor/ | three.js 与 addons，本地静态文件
```

Phase 1 完成清单：

1. 静态站点跑通，`vendor` 内置 three.js。
2. Lenis 与 ScrollTrigger 接线，滚动进度驱动全局时间轴。
3. `layout.js` 驱动建模，换一套布局只需改数据。
4. 图纸层出图：纸面、黑线、房间名、尺寸标注。
5. 墙体升起，含 1.2 m 剖切帧与切面封盖。
6. 镜头段 0 至 3 走通：俯视、下降、进门。
7. 第一间房完成线稿到材质的扫过。

Phase 1 不含：其余房间、全屋家具、傍晚光照调优、后期效果、移动端适配。
